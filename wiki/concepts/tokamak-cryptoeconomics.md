# Tokamak Network 크립토이코노믹스

Tokamak Network의 Optimistic Rollup L2를 위한 경제 설계 문서. TON 유틸리티 극대화, 시뇨리지, 검증 인센티브, 빠른 출금 메커니즘을 다룬다.

---

## 0. 핵심 요약 (TL;DR)

- Tokamak Network는 이더리움 기반 범용 Optimistic Rollup 인프라
- L2 생태계를 육성하는 **TON 시뇨리지**와 **L2 보안을 강화하는 TON 기반 챌린지 인센티브**가 핵심
- L2 운영자의 **L2 수수료 토큰 딜레마**를 시뇨리지로 완화
- **스테이킹 + 빠른 출금** 조합이 검증자의 딜레마를 가장 효과적으로 해결

---

## 1. 용어 정의

| 용어 | 설명 |
|------|------|
| **스테이킹** | TON을 락업해 네트워크 역할(시퀀서 등) 수행 권한 획득 |
| **시뇨리지** | 인플레이션 보상. 블록당 3.92 TON, 연간 약 1,030만 TON (Merge 이후) |
| **시퀀서** | L2 트랜잭션 수집·배치·제출 주체. TON 스테이킹 필요 |
| **챌린지 (DTD)** | 출력 루트의 부정확성을 이의제기하는 절차. Dispute Time Delay (7~14일) |
| **빠른 출금** | DTD 없이 즉시 L1 자산 수령 — 스테이커가 TON으로 유동성 제공 |
| **사기/유효성 증명** | Optimistic Rollup의 검증 방식. 사기 증명(현재) → 유효성 증명(ZK, 미래) |

---

## 2. 시뇨리지 메커니즘

### 2.1 발행량

- 이더리움 블록당 **3.92 TON** 발행
- The Merge 이후 블록타임 12초 기준 → 연간 약 **10.3M TON**

### 2.2 분배 구조

#### Staking V1
```
시뇨리지 = 스테이커 + DAO + sTOS holders
```
- 스테이커 지분율에 비례 분배 (PowerTON 기반)

#### Staking V2 (L2 연동)
```
시뇨리지 = 스테이커 + DAO + sTOS holders + L2 시퀀서
```
- L2 시퀀서 몫 = TVL 비율에 비례
- L2 간 경쟁으로 **TON 유통 생태계** 확장 유도

### 2.3 L2 수수료 토큰 딜레마 완화

**딜레마**: L2 운영자는 ETH vs 자체 토큰 vs TON 중 수수료 토큰 선택이 필요
- ETH: 이더리움 의존성, L1 비용 직결
- 자체 토큰: 가격 변동성, 수용성 낮음
- **TON**: 시뇨리지 보조로 운영 비용 흡수 → **실질적 딜레마 완화**

---

## 3. 검증 경제학

### 3.1 챌린지 절차

1. 시퀀서가 L2 출력 루트 제출 (스테이킹 필요)
2. 챌린저가 **MinChal** TON 담보 예치 후 이의제기
3. DTD (7~14일) 동안 **그룹 챌린지** 허용 (복수 챌린저)
4. 검증 결과:
   - **시퀀서 잘못**: 시퀀서 스테이킹 슬래싱 → 챌린저에게 분배
   - **챌린저 잘못**: MinChal 몰수 → 시퀀서에게

### 3.2 빠른 출금 (Fast Withdrawal)

- 표준 출금: DTD 대기 (최소 7일)
- 빠른 출금: 스테이커가 TON으로 L1 유동성 미리 제공 → 즉시 수령
- 사용자는 수수료 지불, 스테이커는 DTD 후 L2 출금 자산 수령
- **유동성 제공자 = 스테이커** → TON 스테이킹 수요 증가

### 3.3 검증자의 딜레마 (Verifier's Dilemma)

검증 비용(VC)이 검증 보상(VR)보다 클 때 합리적 행위자는 검증을 포기.

**기호 정의:**
- $X$: 시퀀서가 부정직할 확률
- $C$: 부정직 시퀀서 적발 보상 (챌린지 보상)
- $VC$: 검증 비용
- $VR$: 검증하지 않을 때 기대 보상
- $L$: 부정직 적발 시 시퀀서 손실
- $A$: 스테이킹 슬래싱 비율, $S$: 스테이킹 TON
- $FW$: 빠른 출금에 제공한 TON

---

## 4. 세 가지 검증 모델 비교

### 4.1 기본 검증 모델

| | 공식 |
|---|---|
| 검증 기대 보수 | $X \cdot C + VR - VC$ |
| 비검증 기대 보수 | $-X \cdot L + (1-X) \cdot VR$ |

딜레마 임계값 ($X$ 최댓값): **$1/2$** (예: $C=10, L=10, VC=20, VR=10$)

### 4.2 스테이킹 검증 모델

| | 공식 |
|---|---|
| 검증 기대 보수 | $X \cdot C + VR - VC$ |
| 비검증 기대 보수 | $-X \cdot A \cdot S + (1-X) \cdot VR$ |

- $L = A \cdot S$ (슬래싱이 손실 결정)
- 딜레마 임계값: **$1/2$** (기본 모델과 동일)
- **장점**: $A$ 파라미터 조정으로 $L$을 쉽게 제어 가능

### 4.3 스테이킹 + 빠른 출금 검증 모델

| | 공식 |
|---|---|
| 검증 기대 보수 | $X \cdot C + VR - VC$ |
| 비검증 기대 보수 | $-X \cdot (A \cdot S + FW) + (1-X) \cdot VR$ |

- $FW$가 추가 손실로 작용 → 부정직 시퀀서 리스크 증가
- 딜레마 임계값: **$2/13$** ≈ 0.154 (예: $FW=100$ 추가)

### 4.4 모델 비교표

| 모델 | 딜레마 임계 $X$ | 특징 |
|------|:-----------:|------|
| 기본 검증 | $1/2$ | 파라미터 조정 어려움 |
| 스테이킹 검증 | $1/2$ | $A$ 조정으로 동등 효과 달성 가능 |
| 스테이킹 + 빠른 출금 | $2/13 \approx 0.15$ | 가장 안전, FW 클수록 개선 |

→ **스테이킹 + 빠른 출금 모델이 검증자의 딜레마 해결에 가장 효과적**

---

## 5. TON 유틸리티 요약

| 유틸리티 | 메커니즘 |
|---------|---------|
| L2 지속 성장 | 시뇨리지로 시퀀서에게 경제적 인센티브 → L2 운영 비용 완화 |
| L2 보안 강화 | TON 스테이킹 슬래싱 + 빠른 출금 조합 → 검증자 딜레마 해결 |
| L2 수수료 유연성 | 시뇨리지 보조로 TON 수수료 운영 부담 경감 |
| 유동성 공급 | 스테이커가 빠른 출금 유동성 공급 → 스테이킹 수요 창출 |

---

## 6. 유효성 증명(ZK) 도입 시 변화

- 빠른 출금 필요성 소멸 (DTD 자체가 사라짐)
- 챌린지 스테이킹 메커니즘은 유지 (ZK Proof 생성 비용 담보)
- 스테이커의 유동성 공급 역할 → 축소

---

## 7. 수치 예시 요약

### 시뇨리지 분배 (V1)
- 스테이크 1,000 TON, 전체 스테이크 10,000 TON → 10% 지분
- 블록당 3.92 TON × 10% = 0.392 TON/블록

### 챌린지 시나리오
- 시퀀서 스테이킹 1,000 TON, 슬래싱 비율 10% → 적발 시 100 TON 손실
- 챌린저 MinChal 10 TON → 성공 시 슬래싱분 + 보상 수령

### 검증자의 딜레마 수치
- 기본: $X \leq 1/2$ (검증 포기 안전)
- 스테이킹 + FW: $X \leq 2/13$ (더 낮은 임계 → 더 안전)
